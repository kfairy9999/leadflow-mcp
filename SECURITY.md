# Security policy

## Reporting a vulnerability

Email [kfairley9999@gmail.com](mailto:kfairley9999@gmail.com) with a description, steps to reproduce, and the affected version or commit. Please do not open a public GitHub issue for an unfixed vulnerability.

I will acknowledge a valid report as soon as I can and will tell you when a fix is published.

## Supported versions

The `main` branch and the latest GitHub release are supported.

## Scope

This is a small self-hosted project. There is no bug bounty. Auth tokens, the SQLite or D1 database, and any production Worker secrets are in scope. The fictional Northglass Plumbing seed data is not.
